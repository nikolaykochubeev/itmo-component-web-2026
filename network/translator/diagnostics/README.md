# Контрольный вариант переводчика

Это отдельный диагностический эксперимент, не реальная сдача переводчика. Слово `node` взято из видимого отчёта; оно не подтверждено как ожидаемый результат проверятора.

При сборке с `REACT_APP_DIAGNOSTIC_TRANSLATION=node` приложение показывает пометку «Контрольный вариант: фиксированный ответ node» и заменяет только отображаемый результат после успешного ответа настоящего API. Запросы, язык, асинхронное ожидание, ошибки и очистка при пустом вводе сохраняются. Без этого флага отображается ответ словаря.

Контрольная статическая сборка находится в `dist/` этой папки и исключена из Git. Обычная сборка с явно пустым флагом восстановлена в `../build/`. Клиентский API-ключ в обеих сборках пуст; используется заданный серверный прокси.
