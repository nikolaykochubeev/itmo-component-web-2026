## Fetch, упражнение 1

Кнопка на главной странице сравнивает последовательные `await` с `Promise.all` для двух заданных адресов. Замер `performance.now()` включает получение и чтение тела ответа, ошибки HTTP проверяются. Браузер обращается к исходным адресам; оба отвечают `Access-Control-Allow-Origin: *`.

Команда `npm run measure` выполняет тот же код в Node и записывает реальные ответы в `evidence/measurements.json`.

Измерение 28.10.2026: последовательно **13.099 с**, конкурентно **7.735 с**. Это наблюдение конкретного запуска; ожидаемая задержка примерно 12 и 7 секунд плюс сеть.

## Fetch, упражнение 2

Клиент `public/app.js` вызывает `fetch('/api/time')`, читает HTML и извлекает `#theTime` через `extractTime`. Формат AM/PM преобразуется в 24-часовой `HH:MM:SS`. Произвольное время из другого места страницы не принимается.

Сервер `server.js` получает HTML только с заданного WorldTimeServer и возвращает его клиенту с CORS-заголовком. Серверный запрос не ограничен браузерной политикой CORS. Эта прослойка не позволяет проксировать произвольные адреса. Живой ответ проверен через локальный маршрут; результат в `evidence/time-response.json`.

## Чекинатор fetch

- `GET /login` → текст `nkochubeev`.
- `GET /id/{N}` → серверный `GET https://nd.kodaktor.ru/users/{N}`, затем текст из поля `login`.
- Исходящий запрос не содержит тела и заголовка `Content-Type`.
- Ошибка исходного сервера или некорректный JSON возвращает HTTP 502.

Для Moodle нужен публичный корневой HTTPS-адрес запущенного сервера. Статический GitHub Pages не выполняет эти серверные маршруты. На момент проверки `https://nd.kodaktor.ru/users/1` вернул HTTP 404; тест с локальным HTTP-источником подтверждает правильное поведение на успешном JSON и отсутствие исходящего `Content-Type`.

## Финальный React-проект

В `translator/` распакован исходный архив курса. Сохранены React 16, axios и create-react-app. Google Translation заменён на Yandex Dictionary по примеру, на который ссылается страница курса «Yandex API»: `https://kodaktor.ru/ya_trans.js` (исходник `https://web-scriptor.ru/j/ya_trans.js`). Языки ограничены направлениями словаря из русского.

```sh
cd translator
npm install --ignore-scripts --no-audit --no-fund
cp .env.example .env.local
# Указать собственный REACT_APP_YANDEX_DICTIONARY_KEY в .env.local
npm run build
```

Личный ключ берётся в строке 7 `src/components/translate.js`. В проекте ключа нет. Без него приложение собирается и показывает понятное сообщение, перевод через API проверить нельзя. Переменная окружения CRA включается в клиентский JavaScript при сборке; `.env.local` исключён из Git.

Для публикации без ключа в браузерном JavaScript задайте `REACT_APP_TRANSLATE_ENDPOINT=https://ваш-сервер/api/dictionary` перед сборкой. Локально можно задать `/api/dictionary`. Тогда клиент посылает только `text`, `lang`, `ui`, а сервер добавляет секрет из `YANDEX_DICTIONARY_KEY` и вызывает фиксированный адрес Yandex Dictionary. Этот режим имеет приоритет над ключом в клиентской переменной. Переменную серверу нужно передать при запуске; `.env.example` служит образцом, Node 18 автоматически этот файл не читает. Без серверного ключа маршрут отвечает HTTP 503 с объяснением. Тест с локальным upstream проверяет передачу ключа только upstream и его отсутствие в ответе клиенту.

В `build/` получается статический мини-сайт с относительными ссылками на `static/` (`homepage: "."`). Для GitHub Pages необходимо загрузить **содержимое** `build/` так, чтобы `index.html` оказался в корне выбранного источника сайта. Локальный сервер показывает эту сборку по `/translator/`.

Скрипты запуска/сборки добавляют `--openssl-legacy-provider` для старого webpack исходного курса на новых Node.js; глобальная версия Node и настройки ОС не меняются.

Текущая опубликованная версия находится в `translator/standalone` и `/docs`: один HTML с автономным FreeDict/WikDict на 42 283 слова, общим кэшем реальных ответов Яндекса и API для неизвестных слов. Ключ остаётся серверным секретом Sites. 28.10.2026 версия принята проверятором; оценка 100/100 подтверждена в Moodle. Сборка: `node network/translator/standalone/build.mjs --docs` из корня репозитория; тесты: `node --test network/translator/standalone/standalone.test.mjs` (5/5). Лицензия и происхождение данных находятся в `standalone/data`.
