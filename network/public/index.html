Практика fetch

1. Два запроса с задержкой

Сначала выполняются запросы по очереди, затем оба запускаются через Promise.all. Замер включает чтение тела каждого ответа.

  • Задержка 7 секунд
  • Задержка 5 секунд
Ожидается около 12 секунд для последовательных запросов и 7 секунд для конкурентных. Фактическое время зависит от сети.

2. Время Санкт-Петербурга

Клиент получает HTML WorldTimeServer через свой сервер /api/time и извлекает часы, минуты и секунды из #theTime.

--:--:--

Это время в момент ответа источника. Обновление выполняется по кнопке.

Чекинатор fetch

/login возвращает nkochubeev. /id/1 извлекает login из ответа https://nd.kodaktor.ru/users/1. Исходящий GET не содержит Content-Type.
