ИСУ **307482** подтвержден пользователем и записан в Docker-проекте. Имя Docker-образа соответствует обязательному шаблону из дополнительной инструкции GHCR. Публичность и наличие образа проверяются отдельно; одна подготовка исходников публикацией не считается.

Для Web Components нужен собственный аккаунт **npmjs.com**. GitHub npm registry не заменяет npmjs для указанного в PDF проверятора. Временное имя пакета защищено `private: true`, чтобы исключить случайную публикацию под неподтвержденным именем. API-ключи этим двум лабораторным не нужны.

Исходные инструкции курса и извлеченный текст находятся в [instructions](instructions/). У обоих форумов Moodle требуется членство в группе курса. До выдачи этого доступа отправить ответы нельзя.

## Проверки

В каждом проекте выполните `npm test`. Docker-проект использует только встроенные средства Node.js и не требует `npm install`. Для браузерных тестов page-preview сначала выполните `npm ci` и `npx playwright install chromium`.

Дополнительная проверка контейнера: `npm run test:docker` из `docker-fs`. Она создает временный образ, запускает четыре независимых дерева `/data`, проверяет точный stdout, `linux/amd64`, отсутствие сети и readonly mount, после чего удаляет свой образ и тестовые файлы. Настройка ИСУ проекта сохраняется.
