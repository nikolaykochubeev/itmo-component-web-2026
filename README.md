# Компонентное веб-программирование 2026

Работы Николая Кочубеева, ИСУ 307482, Moodle `nkochubeev`.

## Автоматические задания

В локальном комплекте подготовлены решения Callback, Promise1, Promise2, JSX (1) и JSX (2). Личный журнал отправок хранится отдельно от публикуемых исходников.

Для автоматических заданий fetch и «Переводчик» нужны работающие публичные HTTPS-приложения. Реализации находятся в [network](network/README.md). Переводчик требует личного ключа Яндекс.Словаря.

## Локальная проверка

В каждой папке есть собственная инструкция запуска. Тесты используют временные файлы или локальные HTTP-серверы. Данные реального учебного сервера и доступность внешних API могут меняться.

Закрытые преподавателем разделы «Реактивность» и «Дополнительно» недоступны в Moodle на дату подготовки.

## Размещение

Исходники сохранены в публичном репозитории [itmo-component-web-2026](https://github.com/nikolaykochubeev/itmo-component-web-2026). Docker-образ `ghcr.io/nikolaykochubeev/itmo-component-lab:307482` [доступен публично](https://github.com/nikolaykochubeev/itmo-component-web-2026/pkgs/container/itmo-component-lab), [workflow завершился успешно](https://github.com/nikolaykochubeev/itmo-component-web-2026/actions/runs/40611625286). Проверены анонимное скачивание без сохранённых учётных данных и запуск скачанного образа без сети с доступом к файловой системе только на чтение.

[Сервис fetch](https://nkochubeev-fetch-course48.redcharm32.chatgpt.site/) развёрнут публично в Sites. `/login` возвращает точный логин, `/id/7` получил от учебного API значение `Игорь`. При отправке URL в Moodle проверятор возвращает `TypeError: Cannot read properties of undefined (reading 'data')`, в том числе для адреса с обязательным завершающим `/`. Успешная автоматическая сдача fetch пока не подтверждена.

[Клиент переводчика](https://nikolaykochubeev.github.io/itmo-component-web-2026/) опубликован в GitHub Pages из `/docs`. [Та же рабочая сборка на домене API](https://nkochubeev-fetch-course48.redcharm32.chatgpt.site/translator/) доступна отдельно. Прокси Яндекс.Словаря настроен серверным секретом Sites; ключ не включён в исходники и клиентский JavaScript. Настоящий перевод `кот → cat` проверен через API и интерфейс. Начальное поле пустое. `/worldtime` успешно получает страницу сервера времени с `#theTime`.

[Контрольная страница](https://nkochubeev-fetch-course48.redcharm32.chatgpt.site/translator-control/) явно помечена и после успешного API-запроса показывает фиксированный `node`. Это диагностический эксперимент по запросу владельца, не настоящий перевод. Проверятор отклонил и этот вариант; сама подстановка `node` не дала успешного результата. Рабочая программа сохранена отдельно.
